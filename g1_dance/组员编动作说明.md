# G1 动作编辑器 —— 组员使用说明

> 目标：每个人用这个可视化工具给 G1 机器人**编一段动作**（不用写代码），导出文件，最后拼成一套完整的武术 routine 去训练。
> 你只需要：拖滑块摆姿势、看右边机器人预览、存关键帧。**所见即所得。**

---

## 一、准备（每人做一次）

1. 拿到**项目文件夹**（`mujoco-3.10.0-windows-x86_64`，里面有 `g1\` 模型和 `g1_dance\choreographer.py`）。
2. 装 Python 的 mujoco（命令行跑一次，以后不用）：
   ```
   pip install mujoco
   ```
   （没装 Python 的话先装 Python 3.10+。）

---

## 二、打开编辑器

在项目文件夹里，命令行运行：
```
python g1_dance\choreographer.py
```
会弹出**两个窗口**：
- **左边**：29 个关节滑块（分"左腿/右腿/腰/左臂/右臂"五组）+ 操作按钮。
- **右边**：G1 机器人的 MuJoCo 预览窗口（**拖滑块它就实时动**）。

---

## 三、编动作（核心操作）

### 摆一个姿势
- 拖左侧滑块，右边机器人立刻跟着变。
- 嫌从零摆麻烦？点 **【站立】** 或 **【抱架】** 按钮一键复位到常用起势，再微调。

### 存成关键帧
1. 在"**时间(秒)**"框里填这个姿势的时间点（比如 `0.0`、`0.4`、`1.0`、`1.5`……）。
2. 点 **【存关键帧】**。
3. 下面"关键帧列表"会多一条 `t=几秒`。

### 重复
- 摆下一个姿势 → 填下一个时间 → 存关键帧。
- **两个关键帧之间，编辑器会自动平滑过渡**，你不用一帧帧画。
- 例如编一个冲拳：`t=0 抱架` → `t=0.3 左拳打出` → `t=0.5 收回` → `t=0.8 右拳打出` → ……

### 预览
- 点 **【▶ 播放预览】**，机器人会按你存的关键帧顺序动一遍，确认效果。

### 导出（你的成果）
- 点 **【导出 CSV】**，存成**你名字命名的文件**（如 `张三_拳法.csv`）。
- **把这个 CSV 发给负责人**（微信/拷贝都行）。完成！

---

## 四、分工（每人编约 1 分钟）

| 谁 | 编什么 | 大概内容 |
|---|---|---|
| A | **拳法段** | 抱架 → 左右冲拳 → 推掌 → 收势 |
| B | **步型段** | 马步 → 弓步 → 仆步（重心慢移） |
| C | **腿法段** | 正踢/弹踢（量力而行，单腿动作难） |

- 每人编自己的，各自导出一个 CSV。
- **节奏别太快**：一个动作 0.3~0.5 秒过渡，留出停顿。太快机器人训不出来。
- **重心稳着点**：尽量双脚接地、别大幅扭腰甩腿（仿真里容易摔）。

---

## 五、注意事项

1. **滑块已经限了关节极限**，不会掰坏机器人；但**手臂别穿过胸口/身体**（自己看预览，穿模了就调）。
2. **不用记关节正负号**——你是看着机器人拖滑块的，拖到姿势对就行。
3. **小技巧**：编不清某个姿势时，先【站立】复位，再一点点调到目标姿势。
4. **导出前一定先【播放预览】** 看一遍顺不顺。

---

## 六、拼合（负责人做，组员不用管）

负责人收到大家的 CSV 后，合成全套：
```
python g1_dance\combine_routines.py 全套.csv 张三_拳法.csv 李四_步型.csv 王五_腿法.csv
```
段间会自动加 0.3 秒过渡。合成完的 `全套.csv` 会送去穿模检查 + RL 训练。

---

## 常见问题
- **窗口打不开/报错**：确认装了 `pip install mujoco`；确认在项目根目录运行（不是在 g1_dance 里）。
- **右边机器人不动**：点一下右边窗口让它获得焦点；或关掉重开。
- **导出的文件在哪**：默认在 `g1_dance\` 文件夹，导出时也能自己选位置。
