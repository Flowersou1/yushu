## ★关键知识（前一个 AI 踩过的坑，别重踩）
1. **判动作对错 = 只信运动学坐标 + 碰撞检测，不靠看图。** 你有视觉可以用来看"感觉"，但**穿模和拳位/幅度必须用 `check_clip.py` / `verify_csv.py` 的数字拍板**。
2. **G1 关节方向约定（实测，别猜符号）：**
   - `shoulder_pitch`（肩屈伸）：**正值=手臂下垂**（+0.86≈垂手）；**负值=前抬/上举**（越负越往前/上）。注意：要伸直的手臂水平指向前方（拳在胸口高），需要 sp≈-1.1（配 elbow=+1.3）；sp=-0.74 时伸直的手臂会斜向下（拳到 z=0.76）。
   - `elbow`：⚠️ **手臂伸直 ≈ +1.3~+1.5（正值！），不是 0。** elbow=0 时肘内角仅 ~90°（弯成直角），**负值=前臂折回**（更弯）。出拳伸直到 **+1.3**（内角~165°），抱架屈肘用 **-0.7**（内角~59°）。判肘是否真伸直 = 看内角（180=直），跑 `elbow_diag.py`。
   - `shoulder_roll`：左臂正值=向外(左)，右臂负值=向外(右)。
   - CSV 关节顺序：左腿6(hip_pitch,hip_roll,hip_yaw,knee,ankle_pitch,ankle_roll) / 右腿6 / 腰3(yaw,roll,pitch) / 左臂7(shoulder_pitch,shoulder_roll,shoulder_yaw,elbow,wrist_roll,wrist_pitch,wrist_yaw) / 右臂7。
   - 稳定站立腿：`[-0.312, 0, 0, 0.669, -0.363, 0]`（左=右，轻微屈膝，平衡可用）。
3. **防穿模硬约束**：① 负向折肘（前臂折回穿上臂）不能深于 **-1.0**（-1.3/-1.6/-1.8 穿透 -10~-48mm）；抱架屈肘用 **-0.7**（安全）。② 出拳用**正向伸肘(+1.3)**，手臂朝外伸、不穿模。该模型**能检测手臂穿胸**（torso_link 与腕部会报碰撞），所以 `check_clip.py` 可信。每改一版必跑它确认 `[OK] 没检测到任何穿模`。
4. **臂长限制**：G1 肩到拳约 0.28m，出拳拳最远到 x≈+0.30。在「零穿模 + 拳不抬高 + 腿不动站稳」前提下，前伸距离上限就这么多，别指望大幅增加——要更"长"只能靠腰转把肩往前送，或接受这是机器人臂长极限。
5. **腰转方向**：`waist_yaw` 负值→左肩靠前（左冲拳用负），正值→右肩靠前（右冲拳用正）。
